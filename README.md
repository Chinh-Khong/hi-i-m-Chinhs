## ✨ Highlights

- 🪐 **Interactive 3D Solar System** — High-DPI celestial galaxy with real-time 360° drag rotation (`OrbitControls`), planetary rings, and sharp super-sampled badges.
- 🛰️ **Gyroscopic Hero Planet** — 3D core with multi-nested orbiting satellites, live telemetry ribbon, and terminal status brackets.
- 📐 **Vector HUD Schematics** — Interactive visual blueprints for all 6 real-world production platforms with live domain badges.
- 🪟 **Cyber HUD Glassmorphism** — Sleek dark aesthetic with sci-fi reticle corners `[ + ]`, laser scanner beams, and shimmer button effects.
- ⚡ **Ultra-Fast Performance** — Built on Next.js 16 (Turbopack) & React 19, delivering buttery 60 FPS animations.

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/Chinh-Khong/hi-i-m-Chinhs.git
cd hi-i-m-Chinhs

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001` if port 3000 is in use) in your browser.
